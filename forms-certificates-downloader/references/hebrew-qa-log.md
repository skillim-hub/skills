# יומן בקרת עברית

## היקף

נבדקו `SKILL_HE.md`, תיאורי metadata בעברית, כותרות דוגמאות ותיעוד רלוונטי בעברית.

## שינויים שבוצעו

| תחום | שינוי |
|---|---|
| ניקוד | הוסר כל ניקוד מטקסט טכני. |
| קול ניסוח | הוחלף ניסוח אישי בניסוח ציווי ניטרלי. |
| מונחי מס | נעשה שימוש ב"רשות המסים", "מס הכנסה", "מע"מ", "ניכוי מס במקור" ו"דוח שנתי". |
| מונחי ביטוח לאומי | נעשה שימוש ב"המוסד לביטוח לאומי", "דמי לידה", "תביעה" ו"אישור". |
| מונחי הנהלת חשבונות | נעשה שימוש ב"מנהל חשבונות", "חשב שכר", "סגירת חודש" ו"מאגר". |
| תאריכים | נוספה הנחיה להצגת תאריך אנושי בפורמט DD/MM/YYYY, לדוגמה 02/06/2026. |
| מטבע | נוספה הנחיית שימוש בסימן ₪. |
| מונחי מחשוב | נשמרו מונחים מקובלים כגון "קובץ", "תיקייה", "שורת הפקודה", "מאגר", "כתובת" ו"הורדה". |
| מונחים שלא תורגמו | SHA-256, CSV, PDF ו-JSON נשארו כפי שמקובל בתיעוד טכני בישראל. |
| מגדר | נבחרו פעלים בציווי ניטרלי ככל האפשר, כגון "השתמש", "הרץ", "עדכן", "שמור" ו"בדוק". |
| גבולות שימוש | הודגש כי התחברות, הגשה, חתימה והורדת אישורים אישיים נשארות באתר הרשמי. |

## בדיקות

- לא נמצא ניקוד עברי בטקסט הציבורי.
- לא נמצאו מונחים לועזיים כאשר קיים מונח עברי מקצועי נפוץ.
- נשמרה הבחנה בין הורדת טופס ציבורי לבין הגשה לרשות.
- נשמרה הבחנה בין בדיקת מבנה תעודת זהות לבין אימות זהות.

| אימות סופי ברשת | נוספו ניסוחים בעברית שמבהירים שימוש במקורות ציבוריים בלבד, הפרדה בין טפסים לאישורים בביטוח לאומי, ותאריך 02/06/2026. |
| מע"מ | נוסח עברי עודכן ל"שיעור 18% מ-01/01/2025" בלי להפוך את הכלי למחשבון מס או לייעוץ מס. |
| רשות התאגידים | הוחלף ניסוח כללי ב"רשות התאגידים" ו"רשם התאגידים" לפי ההקשר. |
