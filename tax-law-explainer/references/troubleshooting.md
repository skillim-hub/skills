# Troubleshooting Guide

## Diagnostic method

1. Identify the tax type before answering.
2. List supplied facts and missing facts.
3. Check whether the answer depends on current thresholds or official forms.
4. Separate tax liability from registration duty and documentation duty.
5. Provide a lawful correction path for past mistakes.
6. Escalate when facts suggest audit, penalty, real-estate signing, or material amounts.

## Common failures and fixes

### Final tax amount requested with incomplete facts

Risk: false precision. Fix: provide formula, data checklist, and illustrative example only. Ask for dates, amounts, taxpayer status, residence, spouse/family-unit facts, prior transactions, documents, and current certificates.

### Exempt dealer confused with income-tax exemption

Risk: underreporting income. Fix: explain that exempt dealer status concerns VAT collection and input VAT, not income-tax liability.

### Documents requested before registration

Risk: invalid documentation and penalties. Fix: advise registration/status confirmation before issuing tax documents. For urgent payment, describe holding payment or issuing only lawful documents after status is clear.

### Backdating requested

Risk: false document and compliance exposure. Fix: refuse backdating instructions. Offer lawful correction: credit invoice, amended report, disclosure to adviser, explanatory note, and payment of differences.

### Private expense claimed as business expense

Risk: disallowed deduction and audit exposure. Fix: check business purpose, mixed use, reasonable allocation, and documentation. Explain that private consumption remains private.

### Invoice lacks VAT details

Risk: input VAT denied. Fix: ask whether supplier is authorized dealer. Request corrected tax invoice if input VAT deduction is intended.

### Foreign-client VAT depends on actual beneficiary

Risk: incorrect zero-rate treatment. Fix: build a beneficiary matrix: contracting party, recipient of service, location of use, Israeli affiliate involvement, deliverable location, contract terms, and evidence.

### Property sale exemption has hidden issues

Risk: incorrect exemption claim. Fix: check family unit, previous exemptions, gifts, inherited property, construction rights, value cap, residence, and municipal betterment levy.

## Topic-specific issue matrix

| Topic | Red flag | Safer response |
|---|---|---|
| VAT registration | Turnover near threshold | Verify current threshold; prepare status-change plan |
| VAT invoices | Customer demands tax invoice from exempt dealer | Explain document limits; provide receipt wording |
| Input VAT | Invoice in spouse name | Request corrected invoice; examine business ownership |
| Expenses | No receipt | Request duplicate; note weak evidence |
| Withholding | Customer deducted too much | Check certificate validity and payment type |
| Annual return | Foreign bank account | Escalate; check reporting duties |
| Rental income | Multiple apartments | Compare tracks; verify thresholds |
| Real-estate sale | Gift from parent | Check cooling periods and family-unit rules |
| Purchase tax | Buying before selling existing apartment | Check replacement apartment rules and deadlines |
| Audit letter | Deadline passed | Immediate professional review and late-response plan |

## Safe correction paths

### VAT underreported

1. Identify period and invoice.
2. Compare books, bank deposits, and reports.
3. Consult adviser if amount is material.
4. File amended report or correction according to current procedure.
5. Pay tax, linkage, interest, and penalties where assessed.
6. Preserve explanation and documents.

### Income omitted

1. Reconstruct receipts and bank deposits.
2. Identify tax year and income type.
3. Match related expenses.
4. Consult professional disclosure route.
5. Amend return or file missing return according to current procedure.
6. Keep correspondence and payment confirmations.

### Real-estate report error

1. Identify assessment number and transaction.
2. Compare contract, declarations, and supporting documents.
3. Check deadline for amendment, objection, or appeal.
4. Obtain attorney review.
5. Submit correction or objection through the proper channel.

## Escalation checklist

Escalate when amount is material, deadline is within 14 days, Tax Authority letter alleges false books or undeclared income, property contract is not yet signed and tax position affects price, foreign assets exist, family transfer or trust is involved, or concealment/backdating/fabrication is requested.
