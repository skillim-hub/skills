# Migration Checklist

Use this checklist when replacing paper binders, spreadsheets, pinned messages, or older emergency contact packages.

## Inventory

- [ ] Collect current wall sheets.
- [ ] Export spreadsheet contacts.
- [ ] Locate staff phone notes.
- [ ] Locate first-aid kit list.
- [ ] Locate AED location notes.
- [ ] Locate incident log forms.
- [ ] Identify the owner of each source.

## Clean unsafe data

- [ ] Remove former employees.
- [ ] Remove duplicate contacts.
- [ ] Remove ID numbers unless formally required.
- [ ] Remove medical details from public sheets.
- [ ] Remove gate and alarm codes from public copies.
- [ ] Remove unverified volunteer responder numbers.
- [ ] Remove outdated first-aid instructions.

## Normalize

- [ ] Convert English operational dates to `DD-MM-YYYY`.
- [ ] Convert Hebrew-facing display dates to `DD/MM/YYYY`.
- [ ] Normalize Israeli phone numbers.
- [ ] Add contact priority.
- [ ] Add role or relationship.
- [ ] Add exact address.
- [ ] Add AED and first-aid kit locations.
- [ ] Add review date.
- [ ] Split public and private information.

## Build profile

1. Copy the example profile.
2. Replace site details.
3. Add contacts.
4. Add emergency-relevant medical notes only.
5. Run validation.
6. Run strict privacy validation.
7. Generate redacted public sheet.
8. Print and distribute.

## Replace old process

- [ ] Replace wall sheet.
- [ ] Replace staff phone note.
- [ ] Update onboarding material.
- [ ] Train staff.
- [ ] Archive old profile with date.
- [ ] Destroy outdated public copies.
- [ ] Restrict access to full profile.
- [ ] Schedule quarterly review.

## Acceptance criteria

- [ ] Validation passes.
- [ ] At least two contacts exist for production.
- [ ] Emergency dispatch numbers appear above private contacts.
- [ ] No public sheet contains ID numbers or detailed medical notes.
- [ ] AED location is present or explicitly marked unavailable.
- [ ] First-aid kit location is present.
- [ ] Review date is current.
- [ ] Staff drill passes.
