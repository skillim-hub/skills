# Workflow Guide

## Workflow 1: Create a site profile

1. Install the package with `pip install -e .`.
2. Run `create-profile` and store the JSON response.
3. Extract the generated profile id.
4. Validate the profile by id.
5. Add access notes, AED location, and first-aid kit location.
6. Add a secondary contact.
7. Run strict privacy validation.
8. Generate a wallet card.
9. Generate a redacted public sheet.
10. Print the public sheet and store the full profile in a restricted location.

## Workflow 2: Medical emergency in a shop

1. Confirm that the scene is safe.
2. Call 101 for red flags.
3. Use speaker mode.
4. Read the address from the emergency sheet.
5. Assign one person to bring the AED.
6. Assign one person to meet responders outside.
7. Assign one person to clear access.
8. Contact the primary contact after dispatch is active.
9. Follow the dispatcher.
10. Complete the incident log after the urgent phase.

## Workflow 3: Freelancer lone-worker preparation

1. Create a personal profile.
2. Print a wallet card.
3. Place a copy in the work bag.
4. Add allergies and emergency-relevant medication only.
5. Before a high-risk job, send a check-in window to a trusted contact.
6. Include client site address only during the job window.
7. Delete client access notes after job completion.

## Workflow 4: Public and private split

Public sheet:

- Emergency numbers.
- Exact address.
- AED location.
- First-aid kit location.
- Red flags requiring 101.
- Evacuation route.

Private profile:

- Full contact list.
- Medical notes.
- Consent record.
- Sensitive access notes.
- Incident log storage location.

Steps:

1. Create the full profile.
2. Run redaction.
3. Review the public sheet.
4. Print only the public sheet.
5. Restrict the full profile.
6. Train staff on where each copy is kept.

## Workflow 5: Food allergy in a cafe

1. Stop service to the affected person.
2. Ask what was eaten and whether an auto-injector exists.
3. Call 101 for breathing difficulty, swelling, collapse, widespread rash, vomiting, or known severe allergy.
4. Help use the prescribed auto-injector when available and indicated.
5. Keep packaging and ingredient details.
6. Contact the manager after dispatch.
7. Log time, symptoms, food item, batch details when available, and response actions.

## Workflow 6: Quarterly review

1. Confirm every contact number.
2. Confirm contact role and escalation priority.
3. Confirm allergies and medication notes with the person.
4. Check AED location and status.
5. Check first-aid kit contents and expiry dates.
6. Verify local emergency and municipal numbers.
7. Update review date.
8. Run validation.
9. Print updated public sheets.
10. Destroy outdated copies.

## Workflow 7: Staff onboarding drill

1. Ask staff to find the emergency sheet.
2. Ask staff to read the address aloud.
3. Ask staff to locate the AED.
4. Ask staff to locate the first-aid kit.
5. Ask staff to identify five red flags.
6. Ask staff to explain why 101 comes before the owner for red flags.
7. Ask staff to find the secondary contact.
8. Ask staff to explain the public and private split.

Pass when all tasks are completed without prompting.

## Workflow 8: Incident aftercare

1. Store incident logs in a restricted location.
2. Do not circulate medical details in informal groups.
3. Redact names and medical details from broad reports.
4. Review whether 101 was called quickly.
5. Review whether the address was clear.
6. Review whether contacts were reachable.
7. Update the profile and procedure when a gap is found.
