# Hebrew QA Log

## Scope

Reviewed Hebrew public documentation and Hebrew-facing output behavior.

## Changes

| Area | Change |
|---|---|
| Date localization | Changed Hebrew-facing date guidance and estimator output to DD/MM/YYYY. |
| Technical prose | Removed Hebrew vowel marks if present. |
| Voice | Kept direct neutral imperative phrasing for instructions and checklists. |
| Terminology | Preserved professional Israeli terms: אומדן, תכולת עבודה, מע״מ, חשבונית מס, רישיון עסק, היתר בנייה, נגישות, כיבוי אש, בלתי צפוי, קבלן, מפרט, פיקוח. |
| Currency | Confirmed ₪ formatting in Hebrew examples and outputs. |
| Anglicisms | Avoided unnecessary transliteration in technical prose while retaining code enum values inside code-oriented tables. |

## Result

Hebrew documentation is suitable for Israeli consumers, freelancers, and small businesses as professional planning material. Legal, tax, safety, and engineering topics remain framed as review flags rather than formal advice.
