# יומן בקרת עברית

## היקף

נבדקו `SKILL_HE.md`, מטא-נתונים בעברית, דוגמאות הודעות בעברית, ותיעוד ציבורי הכולל מונחים ישראליים.

## תיקונים שבוצעו

| תחום | שינוי |
|---|---|
| פורמט תאריך | עודכן פורמט עברי מוצג ל-`DD/MM/YYYY`, כולל דוגמאות כגון `18/06/2026`. נשמרת תאימות קלט גם לפורמט ישן עם מקפים ול-ISO. |
| מטבע | נשמר שימוש ב-`₪` ובסכומים כמו `₪12,345`. |
| ניקוד | הוסר ניקוד מכל פרוזה טכנית בעברית. |
| קול ניסוח | נשמר ניסוח ציווי תפעולי וניטרלי: בצעו, הגדירו, ודאו, תעדו, שלחו, שמרו. |
| מינוח מקצועי | הוחלף מונח לועזי בתחום ההסעדה ב-`הסעדה` במדריך העברי. |
| מינוח תפעולי | הוחלפו שימושים עודפים ב-מונח לועזי בתחום התפעול בניסוח תפעולי עברי כאשר ההקשר עסק בתפעול אולם, הסעות או יום האירוע. |
| הזמנות ואישורי הגעה | נשמרו ניסוחים טבעיים בישראל: אישור הגעה, מוזמנים, הושבה, הסעות, רגישויות למזון, נגישות, אולם, גן אירועים. |
| תחומי דין וחשבון | נשמרו מונחים מקצועיים: מע"מ, חשבונית מס, קבלה, ניכוי מס במקור, מאגר מידע, הסכמה, הסרה מרשימת תפוצה. |
| אירועי חיים | נשמר מינוח תקין: חתונה, בר מצווה, בת מצווה, ברית מילה, שמחת בת, אירוע משפחתי, אירוע לקוחות. |
| מגבלות מקצועיות | נוסחו נקודות בדיקה משפטיות, רפואיות, דתיות וחשבונאיות ללא מתן ייעוץ מוסמך. |

## בדיקות סופיות

|---|---|
| ניקוד עברי בפרוזה טכנית | 0 מופעים |
| שימוש ב-פורמט ישן עם מקפים בתיעוד עברי | 0 מופעים פעילים |
| שימוש ב-`DD/MM/YYYY` בתיעוד עברי | קיים ומכוון |
| שימוש בסימן `₪` | קיים ומכוון |
| אנגליזמים בולטים שבהם יש מונח עברי מקובל | תוקנו במדריך העברי |
