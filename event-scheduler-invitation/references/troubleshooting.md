# Troubleshooting

Use this reference when an event plan breaks, data looks inconsistent, or a supplier/venue creates operational risk.

## RSVP problems

| Problem | Detection | Likely cause | Fix | Prevention |
|---|---|---|---|---|
| Confirmed count too high | Confirmed > venue capacity | Duplicate households or extra guests accepted informally | Deduplicate by phone and household; call affected guests | Use stable guest IDs |
| Confirmed count too low | Response rate under 50% near deadline | Weak wording or wrong channel | Send direct reminder and make phone calls | Segment elderly, family abroad, and classmates |
| Emoji responses | Replies contain ️ only | Invitation did not ask for exact count | Reply with "כמה מגיעים בפועל?" | Include "נא להשיב במספר המגיעים" |
| Children count missing | Families confirm "4" but no ages | Combined adult/child response | Ask follow-up for children and menu | Add explicit children field |
| Dietary notes vague | "יש רגישות" without detail | Guest avoided details in group chat | Ask private follow-up | Request specific operational need |
| Accessibility discovered late | Guest mentions wheelchair near event date | Initial message omitted accessibility | Call venue and guest immediately | Include accessibility question in first RSVP |
| WhatsApp list outdated | Many undelivered messages | Old phone numbers | Use phone calls/email for failed sends | Normalize and test phone numbers |
| Multiple languages | Guests do not understand Hebrew message | Language not tracked | Send translated message | Add language field |

## Venue problems

| Problem | Risk | Immediate action | Longer-term fix |
|---|---|---|---|
| Minimum guest count too high | Paying for empty seats | Negotiate lower minimum or menu credit | Compare guaranteed minimums before deposit |
| Venue says "accessible" but details missing | Guest exclusion | Request route/toilet/parking photos or written confirmation | Use an accessibility checklist |
| Outdoor plan depends on weather | Unsafe or uncomfortable event | Confirm indoor/covered alternative | Add weather clause in contract |
| Parking insufficient | Late arrivals | Arrange shuttle or overflow lot | Calculate cars, not guests |
| Price quote changes | Budget overrun | Request itemized written quote | Store quote version and VAT terms |
| Supplier entry time too late | Delayed setup | Ask venue for earlier loading window | Put setup times in contract |
| Noise cutoff unclear | Music stopped early | Confirm municipal/venue cutoff | Add sound schedule to run sheet |
| Kashrut certificate unclear | Ceremony/catering issue | Request current certificate and scope | Check before deposit |

## Supplier problems

| Problem | Likely cause | Fix |
|---|---|---|
| Photographer double-booked | No signed contract or vague date | Request written confirmation and backup shooter |
| DJ lacks event details | No run sheet | Send ceremony/reception/dance schedule |
| Shuttle provider asks for final list late | Passenger count missing | Export transport manifest |
| Caterer misses allergy | Dietary list not confirmed | Send named guest list with specific needs |
| Supplier asks for cash only | Documentation risk | Request receipt/invoice and business details |
| Designer arrives without venue access | Supplier entry not coordinated | Add all supplier arrival times to venue call sheet |

## Date and ceremony problems

| Situation | Action |
|---|---|
| Wedding date may conflict with religious/custom restriction | Verify before deposit with the relevant authority or ceremony lead |
| Brit milah date uncertain due to birth near sunset | Treat date as tentative until rabbinic/medical confirmation |
| Baby not medically cleared | Postpone; medical clearance overrides event pressure |
| Bar/bat mitzvah Torah portion conflicts with family travel | Consider separate synagogue and party dates |
| Event crosses midnight | Store exact start/end timestamps and supplier dates |

## Message compliance problems

| Symptom | Risk | Fix |
|---|---|---|
| Bulk message includes sale/promotion | May become advertising message | Separate RSVP from marketing or obtain consent |
| No opt-out text | Guest complaints and compliance risk | Add "להסרה כתבו הסר" where appropriate |
| Guest asks to stop receiving messages | Continued sending risk | Mark opt-out and suppress future messages |
| Guest list shared with supplier broadly | Privacy risk | Share minimum needed data only |
| Sensitive family notes visible to check-in staff | Embarrassment/privacy issue | Split private planner notes from operational list |

## Budget problems

| Problem | Diagnosis | Fix |
|---|---|---|
| Total cost exceeds budget | Venue minimum, per-plate, or supplier add-ons underestimated | Reduce guest count, change day, renegotiate menu, cut extras |
| VAT surprise | Quote did not state VAT included | Request corrected written quote |
| Overtime charge | Event end time exceeded package | Add timekeeper and written overtime rate |
| Security cost surprise | Venue/local requirement omitted | Ask venue for mandatory extras |
| Payment date missed | No milestone tracking | Add due dates and reminders |
| Missing invoice | Supplier closeout incomplete | Request invoice before final payment |

## Recovery playbooks

### 1. Five days before event and 30% have not answered

1. Export no-response guests.
2. Segment by family, friends, work, classmates, elderly.
3. Assign callers.
4. Send short message requiring exact count by tonight.
5. Call VIPs and elderly guests.
6. Move persistent no-response to reserve count, not confirmed count.
7. Update venue with conservative final number and reserve seats if allowed.

### 2. Venue capacity is lower than confirmed guests

1. Stop accepting extra guests.
2. Reconcile duplicates and children.
3. Ask venue for layout options.
4. Add tables only if safety and comfort remain acceptable.
5. Shift non-essential plus-ones to apology/waitlist if needed.
6. Document every change.

### 3. Wheelchair access fails during site visit

1. Identify exact barrier: entrance, toilet, parking, path, seating.
2. Ask venue for immediate solution and written confirmation.
3. Offer guest direct call and realistic options.
4. Change venue/area if barrier is material and unresolved.
5. Keep accessibility notes private.

### 4. Supplier cancels

1. Check contract and refund terms.
2. Ask for replacement referral.
3. Contact backup list.
4. Prioritize critical-path suppliers: venue, food, ceremony, photography, music, transport.
5. Confirm replacement in writing.
6. Update run sheet and payment schedule.

### 5. Weather forecast changes

1. Trigger weather decision deadline.
2. Confirm indoor/covered plan.
3. Update layout, sound, lighting, heating/cooling, signage.
4. Notify suppliers.
5. Send guest logistics only if arrival instructions change.
