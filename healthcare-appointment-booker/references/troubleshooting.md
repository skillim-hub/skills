# Troubleshooting

## Portal does not show the service

Likely causes: different Hebrew taxonomy, referral requirement, district restriction, external institute workflow.

Fix:
1. Search Hebrew synonym.
2. Search broader specialty.
3. Check referral/order status.
4. Call clinic or HMO service center.
5. Ask whether service is booked through an external provider.

## Portal requires referral

Fix:
1. Verify referral exists in the official app.
2. Check validity date.
3. Book family doctor or digital referral request.
4. Ask whether approval/Form 17 is also required.

## No appointments in 30 days

Fix:
1. Expand to nearby cities.
2. Remove provider preference.
3. Try telehealth.
4. Check early morning and evening.
5. Call clinic desk for cancellations.
6. Ask HMO center for district alternatives.

## Imaging booking rejected

Fix:
1. Confirm order code and body area.
2. Confirm approval/Form 17.
3. Confirm institute is contracted with the HMO.
4. Confirm preparation.
5. Rebook after approval appears.

## User provides password, ID, or SMS code

Fix:
1. Do not use the data.
2. Ask user to enter it directly in official channel.
3. Redact/delete from notes if possible.
4. Continue with non-sensitive fields only.

## Caregiver lacks permission

Fix:
1. Stop personal-data handling.
2. Ask for patient/guardian authorization.
3. Continue only with general instructions if permission is absent.

## Symptoms sound urgent

Fix:
1. Stop routine booking.
2. Recommend 101, ER, or HMO urgent hotline.
3. Resume booking only after immediate safety is addressed.

## Language support unavailable

Fix:
1. Search broader area.
2. Ask call center for provider language.
3. Ask whether interpreter support exists.
4. Consider caregiver attendance with permission.

## Accessibility unclear

Fix:
1. Call clinic desk.
2. Confirm entrance, elevator, restroom, exam room, parking, companion policy.
3. Record only confirmed operational details.

## Confirmation missing

Fix:
1. Check app/SMS.
2. Reopen official appointment list.
3. Call clinic with service and time.
4. Do not assume booking succeeded.

## Duplicate appointments

Fix:
1. Review official appointment list.
2. Cancel unneeded duplicate.
3. Save cancellation confirmation.
4. Avoid no-shows.

## Cancellation deadline passed

Fix:
1. Call clinic desk.
2. Ask about options and fees.
3. Record official response.
4. Reschedule if needed.


## Maccabi same-specialty booking blocked

Likely cause:
- Maccabi may block digital booking with a different doctor in the same specialty during the same quarter as part of continuity-of-care rules.

Fix:
1. Read the portal message carefully.
2. Do not retry repeatedly as if it were a technical failure.
3. Contact 3555 or the medical-center office.
4. Ask whether branch manager approval or a different service route is required.
