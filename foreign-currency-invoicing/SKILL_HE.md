# הפקת חשבוניות במטבע חוץ

השתמש בכלי זה להכנת חשבוניות, חשבוניות מס, חשבוניות מס/קבלה, קבלות, חשבוניות זיכוי וקובצי תיעוד חשבונאיים כאשר המחיר המסחרי נקוב בדולר, אירו, ליש"ט, ין, פרנק שווייצרי או מטבע חוץ אחר. שלב שער יציג של בנק ישראל, חשב מע"מ בשקלים, ושמור מסלול ביקורת ברור.

המסמך מספק תמיכה תפעולית בלבד. במקרים חריגים, בעסקאות ייצוא שירותים, בשאלות מוסד קבע או בסיווגי מע"מ מורכבים, קבל אישור מרואה חשבון או מיועץ מס מוסמך בישראל.

## כללי עבודה מרכזיים

1. זהה את סוג המסמך: הצעת מחיר, חשבונית עסקה, חשבונית מס, חשבונית מס/קבלה, קבלה או חשבונית זיכוי.
2. קבע את מועד אירוע המס שמכתיב את השער ואת שיעור המע"מ.
3. שלוף את השער היציג של בנק ישראל למטבע ולתאריך הרלוונטיים.
4. לשליפה לפי תאריך, העדף את ממשק סדרות SDMX של בנק ישראל; השתמש בממשק הציבורי העדכני רק לבדיקת שער נוכחי.
5. אם לא פורסם שער באותו תאריך, השתמש בשער היציג האחרון שפורסם לפניו ותעד את הסיבה.
6. המר את בסיס המס לשקלים לפני חישוב המע"מ.
7. סווג כל שורה: מע"מ רגיל, מע"מ בשיעור אפס, פטור, חיוב עצמי או מחוץ לתחולת מע"מ.
8. הצג סכומים במטבע החוץ לצד בסיס המס, המע"מ והסך הכול בשקלים.
9. שמור את מקור השער, אסמכתאות לקוח, נימוק סיווג המע"מ וקובץ ה-JSON עם מסמכי הנהלת החשבונות.

## שדות חובה מומלצים במסמך

כלול לכל הפחות:

- שם העסק, כתובת, מספר עוסק מורשה או ציון עוסק פטור.
- שם הלקוח, כתובת, מדינה ומספר זיהוי מס אם קיים.
- סוג המסמך ומספר מסמך רציף ממערכת הנהלת החשבונות.
- תאריך הפקה בפורמט DD/MM/YYYY.
- קוד מטבע, סכומי שורות במטבע חוץ ותנאי תשלום.
- שער יציג של בנק ישראל, תאריך השער ויחידת שער אם קיימת.
- בסיס מס בשקלים, סכום מע"מ בשקלים וסך הכול בשקלים.
- סיווג מע"מ ונימוק אסמכתאות לכל שורה שאינה חייבת במע"מ רגיל.

## טיפול בשערי חליפין

השתמש בשער היציג שמפרסם בנק ישראל. יש מטבעות שמפורסמים ליחידה של 100 או יחידה אחרת, ולא ליחידת מטבע אחת. חלק את השער ביחידה שפורסמה לפני המרת סכום השורה. לשליפה ממוכנת לפי תאריך, השתמש בסדרת SDMX כגון `RER_USD_ILS` עם `startPeriod`, `endPeriod` ו-`format=csv`, ושמור את כתובת השליפה והפלט.

דוגמה לין יפני:

```text
שער יציג שפורסם: 2.4000 ₪
יחידת שער: 100 JPY
שער אפקטיבי: 0.024000 ₪ ל-1 JPY
סכום במטבע חוץ: 100,000 JPY
בסיס מס בשקלים: 2,400.00 ₪
```

כאשר לא פורסם שער בגלל סוף שבוע, חג או יום ללא פרסום, השתמש בשער היציג האחרון שפורסם לפני התאריך. אל תשתמש בשער מאוחר יותר למסמך שכבר הופק, אלא אם מופק מסמך מתקן בהתאם לכללי מערכת הנהלת החשבונות.

## סיווגי מע"מ

| סיווג | מתי להשתמש | תוצאת מע"מ | אסמכתאות לשמירה |
|---|---|---:|---|
| רגיל | לקוח ישראלי או עסקה חייבת רגילה בישראל | מע"מ רגיל, לרוב 18% מ-01/01/2025 | חשבונית, הסכם, אישור אספקה |
| שיעור אפס | עסקה הזכאית למע"מ בשיעור אפס, למשל ייצוא מסוים או שירות מסוים לתושב חוץ | 0% מע"מ | תושבות הלקוח, הסכם, הוכחת שימוש בחו"ל ונסיבות השירות |
| פטור | עסקה פטורה לפי דין או מצב עוסק רלוונטי | לא מחויב מע"מ | בסיס הפטור ומעמד העוסק |
| חיוב עצמי | הלקוח אחראי לדיווח מס במנגנון חיוב עצמי לפי הדין הרלוונטי | אין מע"מ פלט ישראלי בחשבונית הספק | מדינת הלקוח, רישום מס, הסכם |
| מחוץ לתחולה | העסקה אינה בתחולת מע"מ בישראל | אין מע"מ ישראלי | ניתוח מקום העסקה |

אל תסווג חשבונית בשיעור אפס רק מפני שהיא נקובה בדולר או באירו. המטבע אינו מבחן המע"מ. בדוק את זהות הלקוח, מקום השימוש, מקום אספקת השירות, חריגים ואסמכתאות.

## דוגמאות מעשיות

### שירות פרילנס בדולר ללקוח עסקי תושב חוץ

קלט:

```json
{
  "currency": "USD",
  "issue_date": "02/06/2026",
  "exchange_rate": "3.70",
  "lines": [
    {
      "description": "Consulting services",
      "quantity": "10",
      "unit_price": "200.00",
      "vat_category": "zero",
      "note": "לקוח עסקי תושב חוץ; נשמרו הסכם והוכחת שימוש בחו\"ל."
    }
  ]
}
```

תוצאה:

```text
סכום נטו במטבע חוץ: 2,000.00 USD
בסיס מס בשקלים: 7,400.00 ₪
מע"מ בשקלים: 0.00 ₪
סך הכול במטבע חוץ: 2,000.00 USD
```

### יישום תוכנה באירו ללקוח ישראלי

```text
סכום נטו: 2,500.00 EUR
שער יציג: 4.02 ₪ ל-EUR
בסיס מס בשקלים: 10,050.00 ₪
מע"מ בשיעור 18%: 1,809.00 ₪
סך הכול חשבונאי בשקלים: 11,859.00 ₪
```

### חשבונית מעורבת

חשב כל שורה לפי סיווג המע"מ שלה. שמור פירוט מע"מ נפרד לכל סיווג. אל תחיל מע"מ בשיעור אפס על כל החשבונית כאשר רק שורה אחת זכאית לכך.

## מקרי קצה

- מקדמה: הפק קבלה או חשבונית מס/קבלה לפי סוג העוסק ושיטת הדיווח. השתמש בשער המתאים למועד אירוע המס.
- חשבונית זיכוי: שמור את מטבע החשבונית המקורית ובדרך כלל את בסיס השער המקורי, אלא אם התקבלה הנחיה מקצועית אחרת.
- החזר חלקי: שייך את ההחזר לשורות ולסיווגי המע"מ המקוריים.
- דיווח על בסיס מזומן: קבע את מועד אירוע המס לפני בחירת שער.
- מספר מטבעות: הפק מסמכים נפרדים או חלקים נפרדים לכל מטבע. אל תערבב מטבעות ללא טבלת המרה ברורה.
- תשלום בשקלים עבור חשבונית דולרית: רשום את סכומי החשבונית במטבע החוץ ואת הפרשי השער בנפרד.
- הפרשי עיגול: קבע אם העיגול נעשה ברמת שורה או ברמת מסמך ושמור עקביות.
- שורות שליליות: העדף תהליך זיכוי במקום שורות שליליות, אלא אם מערכת הנהלת החשבונות תומכת בכך במפורש.
- חסרות אסמכתאות לקוח: חייב במע"מ רגיל עד להשלמת אסמכתאות לסיווג אחר.
- מטבע ללא שער יציג: קבל מקור חלופי תקין רק לאחר אישור מקצועי ותעד אותו.

## רשימת בדיקה לפני הפקה

- אמת את סוג המסמך ואת מועד אירוע המס.
- אמת עוסק מורשה או עוסק פטור.
- אמת את שיעור המע"מ התקף לתאריך ההפקה.
- שמור מקור שער יציג מבנק ישראל.
- שמור יחידת שער למטבעות כגון JPY.
- אמת תושבות לקוח ומקום שימוש עבור מע"מ בשיעור אפס.
- רשום מע"מ בשקלים.
- השתמש במספור רציף מתוך מערכת הנהלת החשבונות.
- שמור JSON, חשבונית PDF, מקור שער ואסמכתאות לקוח יחד.
- העבר חריגים לבדיקה מקצועית לפני הפקה.

## תקלות נפוצות

| סימפטום | סיבה אפשרית | פעולה |
|---|---|---|
| לא נמצא שער | סוף שבוע, חג, מטבע לא נתמך או תקלה זמנית | חפש את השער האחרון שפורסם לפני התאריך ושמור אסמכתא |
| המע"מ גבוה מדי | התעלמות מיחידת שער או חישוב מע"מ כפול | בדוק יחידה, בסיס מס וסיווג שורה |
| לקוח מתנגד למע"מ בשקלים | ההסכם מציין רק סכום במטבע חוץ | הוסף הבהרה שהמע"מ מחושב בשקלים לפי דין ישראלי |
| יבוא להנהלת חשבונות נכשל | פורמט תאריך או מספר שגוי | השתמש ב-DD/MM/YYYY ובנקודה עשרונית ב-JSON |
| סיווג שיעור אפס אינו ודאי | חסרות אסמכתאות או חל חריג | חייב במע"מ רגיל או קבל אישור מקצועי לפני הפקה |

## שימוש מהיר בשורת פקודה

```bash
pip install -e .
pip install -r requirements-dev.txt

CREATE_RESPONSE=$(foreign-currency-invoicing create \
  --env sandbox \
  --currency USD \
  --issue-date 02/06/2026 \
  --exchange-rate 3.70 \
  --lines-json '[{"description":"Consulting","quantity":"1","unit_price":"500","vat_category":"standard"}]')

INVOICE_ID=$(python -c 'import json,sys; print(json.load(sys.stdin)["id"])' <<<"$CREATE_RESPONSE")
foreign-currency-invoicing show --env sandbox "$INVOICE_ID"
```
