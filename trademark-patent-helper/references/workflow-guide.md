# End-to-end workflow guide

## Workflow 1: Café filing a word mark

Facts: Haifa café uses "NUNA CAFÉ" on signage, Instagram, receipts, and packaged cookies.

Steps:

1. Confirm owner: use exact company or individual name.
2. Choose mark format: file word mark first if the name is the main asset; add logo filing only if design has independent value.
3. Search: NUNA, NUNA CAFE, נונה, נונא, נונה קפה.
4. Select classes:
   - Class 43: café services; restaurant services.
   - Class 30: cookies; bakery goods if packaged products are sold.
5. Note that "CAFÉ" is descriptive.
6. Prepare filing packet and verify current fee.
7. Save application number, receipt, and all correspondence.
8. Calendar response deadlines and publication/opposition monitoring.

## Workflow 2: Freelancer protecting a consulting brand

Facts: UX consultant uses "FLOWKITE" for UX audits, product workshops, and SaaS onboarding consulting.

Steps:

1. Decide whether the individual or future company should own the mark.
2. Search FLOWKITE, FLOW KITE, פלואוקייט, פלו קייט.
3. Class 42: user interface design, software design consultancy, website usability testing.
4. Class 41: workshops only if paid training is offered.
5. Class 35: business consulting only if real services are offered.
6. Avoid Class 9 unless downloadable software is sold.
7. Create evidence folder with website screenshots, invoices, proposals, and ads.

## Workflow 3: Cosmetics importer with descriptive geography

Facts: "Dead Sea Glow" for creams, soaps, and bath salts.

Steps:

1. Identify descriptiveness/geographic risk.
2. Search DEAD SEA GLOW, ים המלח, דד סי, גלואו.
3. Class 3: cosmetics, soaps, non-medicated bath salts.
4. Class 35: online retail services only if the store brand is used as a service.
5. Consider a more distinctive house mark.
6. Preserve labels, invoices, supplier agreements, and sales evidence in ₪.
7. Use DD/MM/YYYY dates in Hebrew evidence summaries.

## Workflow 4: SaaS startup with technical invention

Facts: Software reduces encrypted database query latency; public demo planned.

Steps:

1. Stop public demo until filing strategy is confirmed.
2. Check founder assignments and company ownership.
3. Write technical problem, architecture, data structures, and measurable effect.
4. Search encrypted database query optimization, searchable encryption, secure query planner, privacy-preserving index cache.
5. Prepare diagrams: client/server, index, cache, query planner, data flow.
6. Decide Israeli first filing, PCT, or other route with professional review.
7. Keep new improvements confidential until filing.

## Workflow 5: Hardware inventor after public disclosure

Facts: bicycle lock mechanism shown on YouTube on 12/04/2026 and sold to 20 buyers.

Steps:

1. Build exact disclosure timeline.
2. Preserve video, screenshots, view count, sales invoices, buyer countries, and prototype dates.
3. Treat patent novelty risk as red.
4. Check whether any undisclosed improvement remains.
5. Consider trademark for product name or other rights, subject to facts.
6. Seek professional review before filing or sending legal demands.

## Workflow 6: Trademark office action response

Facts: examiner objects that "FAST TAX REFUNDS" is descriptive for tax refund services.

Steps:

1. Identify descriptive elements: FAST, TAX, REFUNDS.
2. Gather evidence only if substantial use exists.
3. Consider rebrand if evidence is weak.
4. Prepare table:
   - objection wording;
   - legal issue;
   - response strategy;
   - evidence;
   - deadline.
5. Avoid arguing that the mark is personally important.
6. Submit response through official channel and save receipt.

## Workflow 7: Patent invention disclosure form

Sections:

1. Title.
2. Inventors.
3. Applicant/owner.
4. Technical field.
5. Problem.
6. Existing solutions.
7. Detailed solution.
8. Novel features.
9. Advantages.
10. Drawings.
11. Alternatives.
12. Prototype/test data.
13. Public disclosures.
14. Planned disclosures.
15. Commercial countries.
16. Ownership agreements.

Example:

```text
Title: Pressure-controlled irrigation valve
Problem: Drip lines fail or waste water when upstream pressure fluctuates.
Solution: A controllable restrictor adjusts flow based on downstream pressure.
Novel feature: zone-specific pressure threshold table.
Drawing 1: valve assembly.
Drawing 2: controller and sensor wiring.
Drawing 3: control-flow chart.
Disclosure: no public disclosure; NDA meetings on 03/05/2026 and 06/05/2026.
```

## Workflow 8: Word mark versus logo mark

Choose word mark when:

- The word/name is the main asset.
- The logo may change.
- The same name appears in several designs.
- Budget supports only one filing.

Choose logo mark when:

- The wording is descriptive but the design is distinctive.
- The visual sign has independent recognition.
- The user wants protection for the exact design.

File both when:

- The brand has high value.
- The word is distinctive.
- The logo is stable.
- Budget supports multiple applications.

## Workflow 9: International planning

Trademark:

1. Decide countries.
2. Consider Madrid Protocol route where appropriate.
3. Verify base application strategy.
4. Translate goods/services carefully.
5. Calendar priority deadlines.
6. Budget by country and class.

Patent:

1. Decide whether foreign protection matters.
2. Calendar Paris Convention and PCT deadlines.
3. Avoid public disclosure.
4. Draft robust first filing.
5. Consider markets, manufacturing countries, investors, and enforcement budget.

## Workflow 10: Consumer copied-product complaint

Facts: a seller copied a kitchen gadget idea posted last year; no patent exists; brand was not copied.

Steps:

1. Identify the copied asset: mechanism, product look, brand, photos, text, or packaging.
2. Patent may be difficult without prior filing.
3. Design rights depend on registration and publication timing.
4. Trademark matters only if a source identifier is copied or confusion exists.
5. Copyright may protect photos or text.
6. Gather original files, publication dates, screenshots, invoices, and competitor pages.
7. Seek legal review before threats.
