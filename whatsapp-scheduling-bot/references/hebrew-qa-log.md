# יומן בקרת איכות עברית

## היקף

נבדקו `SKILL_HE.md`, הודעות הדוגמה בעברית, תרחישי הבדיקה, מדריכי העבודה, הודעות הלקוח שנוצרות בקוד ותיאורי CLI שמוצגים למפעיל.

## שינויים שבוצעו

| תחום | שינוי | סיבה |
|---|---|---|
| תאריכים | עודכן ל-`DD/MM/YYYY` בכל מסמכי הציבור ובפונקציית התצוגה | התאמה לנוהג ישראלי נפוץ במסמכי שירות |
| ניסוח | נשמר ציווי ניטרלי כגון "השתמש", "בדוק", "שמור" | מניעת קול אישי או שיווקי |
| מונחים מקצועיים | נשמרו מונחים כמו "תור", "תזכורת", "ביטול", "שינוי מועד", "מאגר תורים", "בקשת הסרה" | שימוש במונחים טבעיים לעסק ישראלי |
| מחירים | נשמר סימון `₪` בצמוד לסכום | התאמה להצגת מחיר בישראל |
| פרטיות ודין | נשמרו ניסוחים כמו "הסכמה", "בקשת הסרה", "שמירת מידע", "הרשאת גישה" | דיוק תפעולי ללא ייעוץ משפטי |
| ניקוד | לא נמצא ניקוד בטקסט הטכני | קריאות מקצועית ועקבית |
| מגדר | נוסחים ללקוח נשמרו ניטרליים ככל האפשר; כאשר נדרש טיפול מגדרי, נדרש מעבר לנציג | מניעת פנייה שגויה ללקוח |
| הודעות שירות | הופרדו הודעות תור מהודעות שיווק | התאמה לערוץ שירות עסקי |
| תחילית מקום | עודכן חיבור שם עסק עם ב׳ היחס, למשל "בעסק לדוגמה" במקום צורה שגויה | עברית טבעית בהודעות ללקוח |

## נקודות בדיקה למפעיל

- הצג הודעות במכשיר אמיתי לפני שליחה ללקוחות.
- בדוק שמות שירותים בלשון העסק, למשל "ייעוץ ראשוני", "טיפול פנים", "תספורת".
- בדוק כתובות עם מספר בית, עיר והנחיות הגעה כאשר יש צורך.
- אל תכניס מידע רפואי, משפטי או פיננסי רגיש להודעות תזכורת.
