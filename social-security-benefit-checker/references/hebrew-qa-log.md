# יומן בקרת עברית

## גרסה 2.1.0

### מטרת הבדיקה

לאמת שהמדריך בעברית מתאים לשימוש מקצועי בישראל, משתמש במונחים מקובלים, מציג תאריכים וסכומים בפורמט מקומי, ושומר על ניסוח ניטרלי וציווי.

### שינויים שבוצעו

| תחום | שינוי |
| --- | --- |
| מונחי ביטוח לאומי | הוחלפו ניסוחים כלליים במונחים מקצועיים: דמי אבטלה, קצבת נכות כללית, קצבת ילדים, הבטחת הכנסה |
| תעסוקה | נוספו מונחים: שכיר, עצמאי, תקופת אכשרה, חל"ת, סגירת עסק, שירות התעסוקה |
| נכות | נוספו מונחים: ועדה רפואית, אחוז נכות רפואית, דרגת אי כושר, כושר השתכרות |
| הכנסות | נוספו מונחים: הכנסה חודשית, הכנסת משק בית, מבחן הכנסות, מבחן תעסוקה, נכסים |
| תאריכים | הובהר שימוש בפורמט DD/MM/YYYY |
| סכומים | הובהר שימוש בסימן ₪ ובהפרדת אלפים |
| סגנון | נוסח מחדש ללשון ציווי ניטרלית: אסוף, בדוק, דרוש, אמת, הוסף |
| פרטיות | נוספו הנחיות לא להזין מספרי זהות, תיקים רפואיים או פרטי בנק בערוץ לא מאובטח |
| מצבי קצה | הורחבו סעיפים על התפטרות, חל"ת, הורים פרודים, ילד סמוך לגיל 18, רכב ונכסים |
| בקרת לשון | הוסרו סימני ניקוד מטקסט ההסבר הטכני |

### החלטות מונחים

| נושא | מונח שנבחר | נימוק |
| --- | --- | --- |
| Social Security | ביטוח לאומי | זהו השם המקצועי המקובל בישראל |
| Unemployment benefit | דמי אבטלה | המונח הרשמי הנפוץ |
| General disability | קצבת נכות כללית | הבחנה מקצבאות נכות אחרות |
| Child allowance | קצבת ילדים | המונח המקובל באתרי שירות ציבורי |
| Income supplement | הבטחת הכנסה | המונח המקובל בהקשר הזכאות |
| Employment Service | שירות התעסוקה | שם הגוף הרשמי |
| Qualifying period | תקופת אכשרה | מונח מקצועי בתחום הזכאות |
| Work test | מבחן תעסוקה | מונח שירותי מתאים בהקשר הבטחת הכנסה |
| Means test | מבחן הכנסות | מונח מקצועי מובן למשתמשים בישראל |

### בדיקות איכות

- אין ניקוד בטקסט הטכני.
- אין ניסוח בגוף ראשון.
- אין תרגום מילולי כאשר קיים מונח עברי מקצועי.
- תאריכים מוצגים כ-DD/MM/YYYY.
- סכומים מוצגים עם ₪.
- ההנחיות מנוסחות כפעולות לביצוע ולא כהצהרות שיווקיות.
- שמות שדות באנגלית נשמרים רק בתוך דוגמאות קוד או מפתח קבצים.

### הערות להמשך

בדוק מחדש את הנוסח לאחר כל שינוי בתקנות, בטפסים רשמיים או בתהליך שירות התעסוקה. העבר מקרים חריגים לביקורת מקצועית לפני שימוש מול משתמשים.
