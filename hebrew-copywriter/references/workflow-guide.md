# Workflow guide

Use these workflows to transform raw Israeli business briefs into publishable Hebrew copy.

## Workflow 1: local service landing page

Brief:
```json
{
  "business": "טכנאי מזגנים בחיפה",
  "audience": "בעלי דירות ומשפחות",
  "offer": "בדיקה ותיקון מזגנים בקיץ",
  "proof": ["מענה באותו יום באזור חיפה", "חשבונית מס", "אחריות על התיקון"],
  "price": "החל מ-₪250 לביקור",
  "channel": "landing_page"
}
```

Steps:
1. Identify urgency without exaggeration.
2. Mention location and response expectation.
3. Include invoice and warranty only if true.
4. Use starting-price wording.
5. End with a call/WhatsApp הנעה לפעולה.

Output:
```markdown
**כותרת:** המזגן הפסיק לקרר? טכנאי מזגנים בחיפה עם מענה מהיר
**כותרת משנה:** בדיקה ותיקון למזגנים ביתיים, כולל חשבונית מס ואחריות על התיקון.
**גוף:** מתאמים ביקור, בודקים את התקלה במקום, ומקבלים הסבר לפני ביצוע התיקון.
**מחיר:** החל מ-₪250 לביקור, בהתאם לסוג התקלה.
**הנעה לפעולה:** לתיאום ביקור היום
```

## Workflow 2: freelancer quote follow-up

Brief:
```json
{
  "business": "מעצבת מצגות",
  "audience": "מנהלי שיווק בחברות קטנות",
  "offer": "עיצוב מצגת משקיעים",
  "price": "₪3,800 לא כולל מע\"מ",
  "channel": "email"
}
```

Output:
```text
היי,

בהמשך לשיחה, מצורפת הצעת מחיר לעיצוב מצגת משקיעים מלאה.

העבודה כוללת חידוד מבנה הסיפור, עיצוב עד 20 שקפים, התאמה לשפה המותגית וסבב תיקונים אחד. המטרה היא להגיע למצגת ברורה, מקצועית וקלה להצגה מול משקיעים או שותפים.

עלות הפרויקט: ₪3,800 לא כולל מע"מ.

כדי להתחיל, אפשר לשלוח את החומרים הקיימים ואת הדדליין הרצוי, ואחזור עם לוח זמנים מסודר.
```

## Workflow 3: מסחר מקוון product page

Brief:
```json
{
  "product": "בקבוק שתייה תרמי לילדים",
  "audience": "הורים לילדי גן ובית ספר",
  "features": ["שומר קור עד 12 שעות", "500 מ\"ל", "קש מתקפל", "ללא BPA"],
  "price": "₪89 כולל מע\"מ"
}
```

Output:
```markdown
**כותרת:** בקבוק תרמי לילדים שנשאר קר גם ביום ארוך
בקבוק 500 מ"ל עם קש מתקפל, מתאים לגן, לבית הספר ולטיולים. שומר על שתייה קרה עד 12 שעות, קל לפתיחה ונוח לניקוי.
ללא BPA.
**מחיר:** ₪89 כולל מע"מ.
**הנעה לפעולה:** הוספה לעגלה
```

## Workflow 6: Google Ads for עסקים תוכנה כשירות

```markdown
**Headlines**
1. CRM לעסקים קטנים
2. לידים, משימות ומעקב
3. פחות פניות שנופלות
4. מתחילים לעבוד מהר
5. בדקו התאמה לעסק

**Descriptions**
1. ניהול לידים, תזכורות ומשימות מכירה במקום אחד. מתאים לצוותים קטנים שרוצים סדר.
2. תהליך מכירה ברור יותר, מעקב אחרי כל פנייה ותמונה יומית של מה פתוח.
```

## Workflow 9: rewrite translated Hebrew

Bad:
```text
גלה את הפתרון האולטימטיבי שמעצים את המסע העסקי שלך.
```

Better:
```text
קבלו דרך פשוטה לעשות סדר בעסק, לחסוך זמן, ולהבין מה הצעד הבא.
```
