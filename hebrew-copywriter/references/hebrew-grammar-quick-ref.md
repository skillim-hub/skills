# Hebrew grammar and style quick reference

## Gender and number

| Strategy | Use when | Example |
|---|---|---|
| Neutral plural | Broad public | `מקבלים הצעת מחיר תוך יום עסקים` |
| Action noun | הנעה לפעולה or button | `לקביעת שיחה`, `להורדת המדריך` |
| Feminine singular | Women-only personal address | `קבלי תוכנית פעולה ברורה` |
| Masculine singular | Explicit masculine audience | `קבל הצעה מסודרת` |
| Feminine plural | Women's group | `הצטרפו לקבוצה קטנה ומותאמת` |
| Formal neutral | Institutional copy | `ניתן להירשם באתר` |

Avoid:
```text
הירשם/י עכשיו וקבל/י הצעה.
```

Prefer:
```text
משאירים פרטים ומקבלים הצעה מותאמת.
```

## Common replacements

| Weak | Better |
|---|---|
| `הנך מוזמן` | `אפשר להירשם` |
| `פתרון אולטימטיבי` | `פתרון פשוט ל...` |
| `ממקסם פוטנציאל` | `עוזר להגדיל...` |
| `לקחת לשלב הבא` | `לעשות סדר` |
| `צור קשר` | `לקביעת שיחה` |
| `הכי טוב` | Proof-based claim |

## Numbers

- Prices: `₪249`, `₪249 כולל מע"מ`.
- Dates: `03/06/2026`.
- Times: `18:30`.
- Percentages: `15% הנחה`.
- Phone numbers: `050-1234567`.

## Accounting and tax terms

| Term | Notes |
|---|---|
| `עוסק פטור` | Do not translate literally |
| `עוסק מורשה` | VAT-registered business |
| `חשבונית מס` | Tax invoice |
| `קבלה` | Receipt |
| `חשבונית מס/קבלה` | Combined document |
| `הוצאה מוכרת` | Use carefully |
| `דוח שנתי` | Annual report |
| `הצהרת הון` | Capital declaration |
| `מקדמות מס הכנסה` | Income tax advances |
| `ביטוח לאומי` | National Insurance |
| `דיווח דו-חודשי` | Bimonthly reporting if accurate |

## Regulated wording

Avoid:
```text
ננצח בתיק.
```

Use:
```text
נבחן את פרטי המקרה ונגבש דרך פעולה מתאימה.
```

Avoid:
```text
מובטח שתחסכו במס.
```

Use:
```text
נבדוק זכאויות והוצאות מוכרות בהתאם לדין ולנתוני העסק.
```

Avoid:
```text
הטיפול מרפא כאבים.
```

Use:
```text
אבחון מקצועי והתאמת טיפול לפי הצורך.
```

## Tone ladder

1. `ניתן להירשם באתר עד 30/06/2026.`
2. `אפשר להירשם באתר עד 30/06/2026.`
3. `נרשמים באתר עד 30/06/2026.`
4. `רוצים להצטרף? ההרשמה פתוחה עד 30/06/2026.`

Levels 2–3 fit most Israeli small-business copy.

## Hebrew SEO

- Use one natural primary phrase in title and first paragraph.
- Add locality only when the service is local.
- Add helpful FAQs: `כמה עולה ביקור טכנאי?`, `באילו אזורים השירות פעיל?`.
- Avoid repeating the city in every sentence.
