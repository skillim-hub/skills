# יומן בקרת איכות עברית

## היקף

נבדקו `SKILL_HE.md`, דוגמאות פלט בעברית, תבניות סיכום, תרחישי בדיקה ותיעוד ההגירה. הבדיקה התמקדה בעברית ישראלית מקצועית, לשון ציווי ניטרלית, מונחי מס וציות, תאריכים, סכומים והיעדר ניקוד.

## שינויים שבוצעו

| תחום | שינוי |
|---|---|
| תאריכים | עודכן פלט עברי לפורמט `DD/MM/YYYY` |
| מטבע | נשמר שימוש ב-`₪` לסכומים ולספים |
| עצמאים | הועדף המונח עצמאי, עוסק פטור ועוסק מורשה במקום מונחים זרים |
| מסחר מקוון | הועדף המונח מסחר מקוון או חנות מקוונת |
| דוחות | הועדף דוח, סיכום ויומן לפי ההקשר |
| מסים | נשמר שימוש ברשות המסים, מעמ, ניכוי מס במקור, הוראות ניהול ספרים וחשבונית |
| צרכנות | נשמר שימוש בביטול עסקה, מכר מרחוק, הטעיית מחיר ודמי ביטול |
| פרטיות | נשמר שימוש במאגר מידע, מידע אישי, אבטחת מידע והרשות להגנת הפרטיות |
| עבודה | נשמר שימוש במעסיק, תלוש שכר, חובת שמירת מסמכים ועיצום כספי |
| לשון | נוסח לציווי ניטרלי: בדוק, חלץ, סמן, אמת, שמור |
| ניקוד | לא נמצא ניקוד בטקסט הטכני |

## כללי סגנון שנאכפו

- השתמש בעברית טבעית ולא בתעתיק כאשר קיים מונח מקצועי מקובל.
- כתוב פעולות ברורות ולא הבטחות לתוצאה.
- הפרד בין מועד תחילה, מועד פרסום ומועד להגשת הערות.
- ציין אי ודאות כאשר מקור אינו דין מחייב.
- העבר סוגיות מס, פרטיות, עבודה, בריאות ופיננסים לבדיקה מקצועית כאשר ההשפעה גבוהה.

## נקודות בדיקה שנותרו להפעלה שוטפת

- בדוק התאמת מונחים לכל רשות בעת הוספת מקור חדש.
- אמת שמות רשמיים של טפסים, צווים ותקנות מול המקור הרשמי.
- שמור פורמט `DD/MM/YYYY` בדוחות עבריים.
- שמור סכומים עם `₪` כאשר המקור מציין סכום כספי.
