# Skillim — סקילים

Production-grade AI agent skills & MCP servers for the Israeli market:
tax, invoicing, government APIs, Hebrew/RTL, compliance, and business
operations. Every skill ships with bilingual docs (SKILL.md / SKILL_HE.md),
references, and validation scripts.

## Install (Claude Code)

```
claude install github:skillim-hub/skills/<skill-name>
```

## Directory

Skills are one directory each at the repo root. MCP servers end in `-mcp`.
