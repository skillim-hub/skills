# יומן בקרת איכות עברית

תאריך: 03/06/2026

## מטרת הבדיקה

בדוק שהעברית טבעית, מקצועית ומתאימה לעסקים קטנים, עצמאים וצרכנים בישראל. שמור על לשון ציווי ניטרלית, מונחים ישראליים מקובלים, תאריכים בפורמט `DD/MM/YYYY` וסכומים ב-`₪`.

## שינויים שבוצעו

| תחום | שינוי | סיבה |
|---|---|---|
| תאריכים | הוחלף שימוש ב-`DD-MM-YYYY` ל-`DD/MM/YYYY` | התאמה להצגת תאריך נפוצה בישראל |
| מטבע | הודגש שימוש ב-`1,250 ₪` במשפט עברי וב-`₪1,250` בתוויות קצרות | שמירה על קריאות בערוצים שונים |
| הנהלת חשבונות | חוזקו `חשבונית מס`, `חשבונית מס/קבלה`, `קבלה`, `מע״מ`, `ניכוי מס במקור` | מניעת תרגום כללי מדי |
| מסמכי עסק | נוספו `עוסק פטור`, `עוסק מורשה`, `אישור ניכוי מס במקור` | התאמה לשימוש של עצמאים ועסקים קטנים |
| צרכנות | חוזקו `החזר כספי`, `דמי ביטול`, `ימי עסקים`, `אחריות` | התאמה לשירות לקוחות ולצרכנים |
| פרטיות | חוזקו `מדיניות פרטיות`, `מידע אישי`, `נושא מידע`, `ספקי שירות`, `הסכמה` | מניעת תעתיק ושמירה על מינוח מקצועי |
| נגישות | חוזק `הצהרת נגישות` | התאמה לאתרי עסקים ושירותים בישראל |
| משפטי | חוזקו `הסכם שכירות`, `שטר חוב`, `ייפוי כוח`, `ערבות` | מניעת הרחבה לא מדויקת של משמעות משפטית |
| מגדר | הועדפו ניסוחים כגון `נשמח לסייע`, `יש לשלוח`, `אפשר להמשיך` | שמירה על ניטרליות כאשר המגדר לא ידוע |
| ביטויים | הובהר טיפול ב-`סבבה`, `על הפנים`, `חבל על הזמן`, `תכלס` | תרגום לפי כוונה ולא לפי מילים |
| ניקוד | הוסר ניקוד מפרוזה טכנית ציבורית | התאמה למסמכי עבודה מקצועיים |

## החלטות ניסוח

- השתמש ב-`דוא״ל` ולא בתעתיק באנגלית כאשר מדובר במונח כללי.
- השתמש ב-`מסרונים` כאשר ההקשר עברי מלא, ושמור `SMS` כאשר הוא מופיע כמונח ממשק או בערוץ המקורי.
- השתמש ב-`מסחר מקוון` במסמכי עיון, ושמור `e-commerce` כאשר מדובר בשם תחום באנגלית.
- השתמש ב-`ממשק שורת פקודה` בעברית, ושמור `CLI` בקוד ובפקודות.
- השתמש ב-`כתובות אינטרנט` בעברית, ושמור `URL` בטבלאות טכניות כאשר נדרש דיוק.

## בדיקות שבוצעו

- אין ניקוד בפרוזה טכנית ציבורית.
- אין תעתיק כאשר קיים מונח עברי מקצועי.
- קיימת התאמה עקבית ל-`₪` ול-`DD/MM/YYYY`.
- קיימת הפרדה בין משלב רשמי, עסקי, מדוברת, שירותי, רגיש משפטית ורגיש חשבונאית.
- קיימות הערות בדיקה עבור משפטי, מס, הנהלת חשבונות, פרטיות ונגישות.
- קיימת שמירה על שמות מוצר, מספרי הזמנה, כתובות אינטרנט, דוא״ל וקודי קופון.
