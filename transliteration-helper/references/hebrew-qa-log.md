# יומן בקרת איכות בעברית

תאריך: 03/06/2026

## היקף בדיקה

נבדקו `SKILL_HE.md`, תיאורי המטא-נתונים בעברית, דוגמאות בעלות הקשר ישראלי, ותוכן ההפניות שמשפיע על שימוש בישראל.

## עקרונות עריכה

- השתמשו בלשון ציווי ניטרלית ורבים: שמרו, בדקו, השתמשו, אל תדרסו.
- העדיפו מונחים ישראליים מקצועיים: חשבונית, קבלה, הצעת מחיר, עוסק פטור, עוסק מורשה, ייבוא, ייצוא, תור בדיקה, מקור איות.
- שמרו סימון מטבע ישראלי באמצעות ₪.
- השתמשו בפורמט תאריך `DD/MM/YYYY` בדוגמאות ישראליות.
- הסירו ניקוד מפרוזה מקצועית ומטבלאות הסבר ציבוריות.
- שמרו מונחי קוד ושמות קבצים באנגלית כאשר הם מזהים רכיב טכני אמיתי.

## שינויים שבוצעו

| אזור | שינוי |
|---|---|
| פתיח עברי | הוחלף ניסוח מוצרי בניסוח פעולה מקומי וניטרלי |
| קהל יעד | הוחלף מונח זר למונח עצמאים |
| הוראות שימוש | חודדה ההבחנה בין איות רשמי לבין תעתיק שנוצר במערכת |
| תאריכים | כל דוגמאות התאריך שונו ל-`DD/MM/YYYY` |
| דוגמאות כספיות | נשמר סימון ₪ בדוגמאות חשבונית וביקורת פנימית |
| ניקוד | הוסרו סימני ניקוד מהטקסט הציבורי ונוספה טבלת השפעה כללית ללא סימון מנוקד |
| רשימת בדיקה | חוזק ניסוח ציווי ניטרלי ללא גוף ראשון |
| אינדקס קבצים | עודכנו שמות הקבצים לאחר מעבר למודול הלקוח התקין |

## תוצאת בדיקה

הטקסט העברי מוכן לשימוש מקצועי בישראל עבור עסקים קטנים, עצמאים וצרכנים, בכפוף לכך שתעתיק אוטומטי אינו מחליף איות רשמי בדרכון, בבנק, בחוזה או במסמך מחייב אחר.
