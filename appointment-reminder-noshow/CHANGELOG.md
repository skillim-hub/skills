# Changelog

All notable changes to this project are documented in this file.

The format follows Keep a Changelog, and this project uses semantic versioning.

## [0.3.0] - 2026-06-05

### Added

- Added comprehensive English and Hebrew skill guides with examples, decision tree, troubleshooting, and anti-patterns.
- Added web-validated Israeli API and regulation reference with access dates, rates, thresholds, official service paths, provider endpoint paths, and error tables.
- Added typed Python client for reminder planning, Hebrew message rendering, quiet-hour handling, provider sending, reply classification, and no-show tracking.
- Added Click CLI for phone validation, message rendering, reminder planning, provider send, stats, and re-booking suggestions.
- Added pytest suite with coverage for phone validation, consent routing, quiet hours, provider payloads, async sending, CLI behavior, and no-show stats.
- Added troubleshooting and test scenario references.
- Added MIT license, pyproject metadata, and development requirements.

### Changed

- Replaced stub content with production-oriented guidance for Israeli service businesses.
- Bumped package version from 0.1.0 to 0.3.0.
- Expanded metadata tags and entrypoints.

### Removed

- Removed contributor metadata.
- Removed promotional visual assets and distribution callouts.
